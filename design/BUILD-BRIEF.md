## Motion & delight
- Hero: three banners slide in from the right 24 px + fade, 140 ms stagger, ease-out-expo 520 ms, front lands last; then the grid overlay draws itself (lines grow from top-left, 600 ms) and the tag pops. Reduced motion = final frame.
- Why: Herald column rows highlight one by one on enter; "Never." row gets an underline draw.
- Flow: scroll-linked: JSON fields light, fly into grid cells, the banner assembles.
- Designer: hotspots as above; one interactive toy — drag the Rive chip into the empty cell if feasible, else skip.
- Actions: the confirmation demo plays once on enter (Deploy clicked by an invisible cursor → Yes/Cancel strip → back).
- Living with it: stack counter 1→7 as faded banners collapse; quiet-hours range fills 22:00–07:00; waveform plays once on click with a real sample if available.
- For agents: install buttons flip to "Installed ✓"; tool list types itself in mono (20 ms/char) on first view.
- Easter egg: ⌘⇧H shows a real-looking Herald banner "You found it." with a Snooze that returns in 10 s.
- Global: transform/opacity only, ease-out-quart/quint/expo, exits 75 % of entrances, prefers-reduced-motion disables all but hover feedback. No glow.
